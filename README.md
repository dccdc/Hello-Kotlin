# 🖱️ 鼠标录制回放工具

一个简单轻量的跨平台鼠标操作录制和回放工具，支持 Windows、macOS 和 Linux。

## ✨ 功能特性

- 🎥 **录制鼠标操作**：记录鼠标移动、点击、滚轮等所有操作
- ▶️ **回放操作**：精确按时间轴回放录制的鼠标操作
- 🔄 **循环播放**：支持无限循环自动回放
- ⚡ **速度控制**：可调节回放速度（0.5x - 2.0x）
- 💾 **保存/加载**：录制内容可保存为文件，方便后续使用
- 🎨 **简洁GUI**：直观的图形界面，操作简单
- 🌍 **跨平台**：支持 Windows、macOS、Linux

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行程序

```bash
python main.py
```

## 📖 使用说明

### 录制鼠标操作

1. 点击 **"🔴 开始录制"** 按钮
2. 执行你想要录制的鼠标操作
3. 点击 **"⏹️ 停止录制"** 结束录制

### 回放鼠标操作

1. 完成录制后，选择是否 **"循环播放"**
2. 选择回放速度（0.5x - 2.0x）
3. 点击 **"▶️ 开始回放"** 开始自动回放
4. 需要时点击 **"⏹️ 停止回放"** 停止

### 保存和加载

- **💾 保存录制**：将当前录制保存为 JSON 文件
- **📂 加载录制**：从文件加载之前的录制
- **🗑️ 清空**：清空当前录制内容

## 🛠️ 技术栈

- **Python 3.7+**
- **pynput**：跨平台的鼠标/键盘控制库
- **tkinter**：Python 内置的 GUI 库

## 📦 打包为可执行文件

如果想要打包成独立的可执行文件（不需要 Python 环境）：

### 安装 PyInstaller

```bash
pip install pyinstaller
```

### Windows 打包

```bash
pyinstaller --onefile --windowed --name="鼠标录制回放工具" --icon=icon.ico main.py
```

### macOS 打包

```bash
pyinstaller --onefile --windowed --name="MouseRecorder" main.py
```

### Linux 打包

```bash
pyinstaller --onefile --name="mouse-recorder" main.py
```

打包后的可执行文件在 `dist` 目录中。

## ⚠️ 注意事项

1. **权限要求**：
   - macOS 需要在"系统偏好设置 → 安全性与隐私 → 辅助功能"中授权
   - 部分 Linux 发行版可能需要 root 权限

2. **屏幕分辨率**：
   - 录制和回放最好在相同分辨率下进行
   - 不同分辨率可能导致坐标偏移

3. **安全使用**：
   - 注意保护录制文件的安全
   - 谨慎回放包含敏感操作的录制
